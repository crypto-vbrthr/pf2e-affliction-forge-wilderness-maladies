# Changelog

## 0.1.0

- Initial Wilderness Maladies library release.
- Added 32 original staged afflictions from levels 0–20.
- Added broad wilderness habitat coverage for Creature Forge matching.
- Added diseases, natural poisons, and primal curses.
- Added semantic Creature Forge tags using contract 1.0.0.
- Added DE/EN localization.
- Added advanced stage mechanics using the existing Affliction Forge runtime.
- Added Foundry 14-safe managed compendium synchronization.
- Added schema, localization, semantic-tag, habitat-coverage, portability, and runtime smoke tests.
